Specification of Video/Audio Encoder preset format for skyerip. Version 0.0.1-draft2.1. 2026-07-31 16:20 CEST
File extension: .srps

The program should place switches in the user-provided order, shall the user-provided switch not reside in the switch database the program shall display a warning instructing the user to either update the definition or check the preset file for typos.

$INPUT *MUST* be provided by the user to place the input, otherwise it is assumed that the encoder reads from stdin BY DEFAULT WITHOUT ANY ADDITIONAL INPUT

output is always placed at the very end.

WARNING: IN-FILE COMMENTS WILL RESULT IN UNDEFINED BEHAVIOUR.

Contents: (plain text readable *IF* reasonably easy to implement)
Version number, ended by \n
path to encoder, ended by \n (For ease of implementation AND readability)
additional switch required for output (if none then '\n' shall be there)
definable switches listed in one string separated with commas e.g. "crf=[0-51],refine-mv=[0-3],rc-lookahead=[1-250],keyint=[0-9999]" //TODO: MOVE TO SEPARATE ENCODER DEFINITION FILE, AND SIMPLIFY IT DOWN TO DEF_FILE, VARIABLES.
Defined switches listed in same fashion as previous field
$en used as a magic phrase for switches which use other variables
EOF

Example (preset based off of preset on https://ffmpeg.party/guides/x265/ ):
0.0.1a
/usr/bin/x265

crf=[0-51],preset=[1-9],no-open-gop=[0-1],keyint=[1-9999],gop-lookahead=[0-9999],rc-lookahead=[1-250],hme=[0-1],hme-search=[$hme1,$hme2,$hme3],strong-intra-smoothing=[0-1],rect=[0-1],aq-mode=[0-4],rd=[0-6],refine-mv=[0-3],rd-refine=[0-1]
crf=21.5
preset=7
no-open-gop=1
keyint=500
gop-lookahead=12
rc-lookahead=100
hme=1
hme-search=$en
hme1=2
hme2=2
hme3=3
strong-intra-smoothing=0
rect=0
aq-mode=4
refine-mv=2
rd-refine=1
$INPUT
EOF
